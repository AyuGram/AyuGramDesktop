# LupinGram Desktop

Закрытый клиент Telegram в зелёном «терминальном» стиле на базе открытого кода
[Telegram Desktop](https://github.com/telegramdesktop/tdesktop).

* Вход по инвайт-ключу (`LPN-XXXX-XXXX`), проверка на сервере LupinGram при запуске.
* Настройки приватности и удобства: **Настройки → LupinGram**.
* Лицензия **GNU GPL v3** (см. `LICENSE`), как и у исходного кода: исходники каждой сборки лежат в этом репозитории.
