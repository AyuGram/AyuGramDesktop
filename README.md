# Drakeygram

Independent Telegram Desktop client fork.

## Features

- Full ghost mode (flexible)
- Messages history
- Anti-recall
- Font customization
- Streamer mode
- Local Telegram Premium
- Translator
- Media preview & quick reaction on force click (macOS)
- Enhanced appearance

And many more.

## Important

This is a fully independent fork.  
**There are zero connections to AyuGram servers, domains, or services.**

All remote config, language pack fetching from external AyuGram CDNs, developer lists, and donate links have been removed or disabled.

## Building

Follow the standard Telegram Desktop build instructions for your platform.  
The project structure is compatible with the official tdesktop build system.
