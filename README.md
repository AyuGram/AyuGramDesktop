# LupinGram Desktop

A private Telegram client with a green "terminal" look, built on top of the open-source
[Telegram Desktop](https://github.com/telegramdesktop/tdesktop) codebase.

* Access is by invite key (`LPN-XXXX-XXXX`), checked against the LupinGram server on start.
* Privacy and quality-of-life options live under **Settings → LupinGram**.
* Distributed under the **GNU GPL v3** (see `LICENSE`), which is the license of the upstream code:
  the source for every build is this repository.
